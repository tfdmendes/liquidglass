Scope and reproducibility
The backdrop is embedded SVG, displacement maps are generated by each actual runtime, and replay uses the same numbered frames. At rest, pressed and moving controls wait 360 ms for settling. No network, build or CDN is needed to open this HTML.
Live frames use identical dimensions in this browser. Overlay puts them in the same cell; wait for resize settling before judging. Single-runtime captures use ?single=original or ?single=candidate, plus &scenario=pressed. Automation can await window.comparisonReady and use runComparison(name); window.lastResult.done confirms completion.
Desktop browser emulation does not establish physical iPhone behavior. Native WebKit runs at the display's DPR 2. Hidden-element/offscreen tests do not prove every background-tab suspension policy. Results apply to tested states and browser builds.
