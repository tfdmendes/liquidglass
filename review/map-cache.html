Evidence, assumptions and limits

Compare the same engine, viewport, DPR and state. “Moving” pauses the real upstream spring after eight 60 Hz steps, then waits for the requested maps to decode. Replay uses those same steps in both panes. With reduced motion, the upstream spring jumps to its target.

Candidate retains at most 48 map entries and 8 MiB of comparison RGBA data. Larger individual maps still use the exact geometry-key cache without keeping their pixel buffer. All map bytes are compared, so there is no hash collision risk.

Map PNGs are checked byte for byte. Rendered captures use delta 0 in Gecko and delta ≤1 per channel in Chrome; Chrome baseline-versus-baseline captures show the same 1-value variation.
